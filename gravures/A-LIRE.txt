par le script de index.html :

Sources conseillées (domaine public) :
  - Gallica (BnF)        https://gallica.bnf.fr
  - Wellcome Collection  https://wellcomecollection.org (filtre licence Public Domain / CC0)
  - Wikimedia Commons    https://commons.wikimedia.org
  - Internet Archive     https://archive.org

Préparation des scans :
  - recadrage serré sur la planche, fond clair ;
  - largeur ≤ 1200 px, JPEG qualité ~82 ;
  - pas besoin d'harmoniser les teintes : le CSS applique sepia(.25).

Vérifier la licence exacte de chaque fichier avant publication et
noter la source (elle pourra être créditée sur la future page
« collection de gravures »).

Tant qu'un fichier manque, l'accueil affiche proprement un cadre
vide annoté (aucune image cassée).
