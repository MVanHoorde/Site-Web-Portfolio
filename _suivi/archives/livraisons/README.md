# Notes de livraison — archive

Ces fichiers **racontent** une session de travail : ce qu'une archive delta
contenait, comment l'extraire, ce qui restait ouvert ce jour-là. Ils ont vécu à
la racine du dépôt jusqu'au 02/09/2026, où ils ont été déplacés ici.

🔴 **Aucun n'est une consigne, et aucun ne décrit l'état courant.** Certains
portent un nom impératif — `A-LIRE-DABORD.md` est une procédure d'extraction du
23/07/2026 — mais tous sont périmés par construction : ils décrivent le dépôt
tel qu'il était le jour de la livraison.

Ce qui fait foi, aujourd'hui :

| Pour savoir… | Ouvrir |
|---|---|
| où on en est | `_suivi/ETAT-PROJET.md` |
| pourquoi c'est comme ça | `_suivi/DECISIONS.md` |
| comment produire | `_modeles/CONSIGNES-*.md` |
| par où entrer | `MANIFESTE.md` |

N'ouvrir un fichier d'ici que sur une question précise — retrouver le détail
d'une passe, vérifier ce qui avait été livré à une date donnée.
